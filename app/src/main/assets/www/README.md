# تطبيق مانجا بيور — نسخة 10

## الجديد
1. **حسابات**: إنشاء حساب/تسجيل دخول بالإيميل. الإيميل `ezjerry53@gmail.com` يصير **إدارة** تلقائياً (بعد تأكيد الإيميل).
2. **لوحة الإدارة** (مخفية — تظهر بالدرج الجانبي للمدير بس):
   - **استيراد**: الصق رابط موقع ← "فحص الرابط" ← "بدء الاستيراد". 70 عامل، كل عامل ياخذ عمل لحاله ويخلصه بالكامل (الاسم، الغلاف، التقييم، القصة، التصنيفات، الحالة، كل الفصول بصورها) وبعدها ينتقل للي بعده. بدون تكرار وبترتيب الموقع.
   - **حذف كل شي** بقاعدة البيانات (يطلب كتابة كلمة "حذف" للتأكيد).
3. تطبيق البروكسي (Flask) **ما تغيّر** — المستورد يستخدمه كما هو عبر `http://127.0.0.1:8080/?url=...`.

## خطوات التفعيل (مرة وحدة)
1. **Firebase Console ← Authentication ← Sign-in method**: فعّل **Email/Password**.
2. سجّل حساب من التطبيق بإيميل الإدارة، افتح رسالة التأكيد بإيميلك (شوف Spam)، ثم "حدّث الحالة" بصفحة حسابي.
3. **حماية قاعدة البيانات (مهم)**: Firebase Console ← Firestore ← Rules ← الصق محتوى `firestore.rules` ← Publish.
   بدونها القواعد القديمة (`allow read, write: if true`) تخلي أي شخص يكدر يكتب/يحذف مباشرة، لأن إخفاء اللوحة بالواجهة لحاله ما يحمي القاعدة.

## الاستيراد
- شغّل تطبيق البروكسي أول، وخليه شغّال بالخلفية.
- الرابط يكدر يكون: صفحة قائمة الأعمال، أو الرئيسية، أو عمل واحد.
- إذا انقطع الاستيراد، شغّله مرة ثانية بنفس الرابط: المكتمل يتخطاه والناقص يكمّله.
- كل الأعمال تتخزّن بنفس بنية مكتبتك: `manga/{id}` وفصولها `manga/{id}/chapters/{id}` (الصور تنحفظ كروابط).
- التحليل عام (يدعم قوالب شائعة + احتياطات عامة)؛ إذا موقع ما انقرأ صح، "فحص الرابط" يوريك شنو لقى قبل ما تبدأ.

## ملفات جديدة
`auth.js` (الحسابات) • `importer.js` (محرك الاستيراد) • `admin.js` (صفحة الحساب + لوحة الإدارة) • `firestore.rules`
